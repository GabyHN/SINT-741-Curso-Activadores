## Cómo se registra un comentario nuevo

1. Si llega por issue, se enlaza el issue en la columna "Comentario".
2. Se decide en la reunión o en el mismo issue: incorporar, posponer o descartar, explicando el motivo.
3. Se actualiza esta tabla en el mismo pull request que hace el cambio.
